## Run locally

Baboon now runs entirely in the browser; no Python server is required.

```sh
npm install
npm run dev
```

Open the local URL printed by Vite and allow camera access when prompted.

## Deploy to Vercel

Import this repository into Vercel and deploy it with the detected SvelteKit settings. Pose detection and gesture classification run on the user's device, so no backend service or environment variables are needed.
